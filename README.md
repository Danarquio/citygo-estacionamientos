# CityGo · Estacionamientos de visita

Aplicación web para el control de estacionamientos de visita del Edificio CityGo.

- Croquis interactivo con puestos EV y EM.
- Estados blanco, verde, amarillo y rojo.
- Tiempo máximo de visita: 6 horas.
- Alertas visuales y sonoras.
- Avisos por Gmail con mensaje prellenado.
- Historial local en el navegador.
- Reporte mensual de infracciones y exportación CSV.

Los registros se almacenan únicamente en el navegador del computador de conserjería mediante localStorage.
